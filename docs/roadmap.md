# Roadmap

## Phase 0 - Project Memory

- Create collaboration docs.
- Capture initial product idea.
- Record early technical decisions and open questions.

## Phase 1 - Static Prototype

- Create a web page. Done.
- Add a map centered on a chosen default location. Done.
- Add a location input. Done.
- Show mock color-coded travel-time bands. Done.
- Improve the mock overlay so it is visually closer to real isochrones.
- Decide whether the next prototype should use a free hosted API or a local routing engine.

## Phase 2 - Real Isochrones

- Choose a travel-time provider.
- Connect the frontend to real driving-time polygons.
- Support a few time bands.
- Add basic loading and error states.

## Phase 3 - Gift Map

- Improve visual styling.
- Add labels and points of interest.
- Add export as image or PDF.
- Save a map configuration for a recipient.

## Phase 4 - Advanced Travel Modes

- Add walking, cycling, or public transport where data allows.
- Add traffic-free, typical traffic, and live traffic options if supported.
- Compare multiple origins or destinations.

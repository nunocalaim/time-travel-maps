# Open Questions

## Product

- Who is the first intended recipient of a gift map?
- Should the first map feel more practical, more decorative, or both?
- What travel-time bands should be shown first: 10/20/30/45/60 minutes, or something else?
- Should the map show destinations inside each band, such as towns, beaches, hospitals, restaurants, or train stations?

## Data And APIs

- Which travel-time provider should the prototype use?
- Do we need current traffic immediately, or is traffic-free driving time enough for version one?
- Can generated travel-time data be cached or committed to the repo under the provider's terms?
- What geographic regions matter first: Portugal, Europe, US, or global?

## Map Rendering

- Should the first version use Mapbox, MapLibre, Leaflet, or another map library?
- Should overlays be rendered as true isochrone polygons, raster tiles, or sampled grid cells?
- How detailed should country-scale overlays be before performance becomes painful?

## Collaboration

- Should each branch maintain a separate branch note?
- Should agent session summaries be updated manually or generated after every substantial session?

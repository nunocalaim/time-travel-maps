# Collaboration Guide

This project welcomes collaboration between humans and AI agents.

The repo should record useful project memory, not full transcripts. A future collaborator should be able to understand what was tried, what was decided, and what remains open without reading every conversation.

## Files

- `agent-log.md`: chronological summaries of work sessions.
- `goals.md`: current product and technical goals.
- `open-questions.md`: unresolved questions and tradeoffs.
- `human-notes.md`: personal notes, observations, and preferences from human collaborators.
- `branches/`: notes about branch-specific experiments or divergent project directions.
- `docs/decisions/`: durable decision records.

## Session Summary Template

```md
## YYYY-MM-DD - Short session title

Participants:
- Human:
- AI:

Goal:
- What we were trying to do.

Decisions:
- What was decided.

Tried:
- What was explored or tested.

Open Questions:
- What still needs thought.

Next:
- What should happen next.
```

## Branch Notes

When a branch explores a different direction, add a file in `collaboration/branches/`.

Branch notes should say:

- why the branch exists;
- how it differs from `main`;
- what assumptions it is testing;
- what would make it worth merging;
- what would make it worth abandoning.
